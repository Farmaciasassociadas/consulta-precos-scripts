# Contexto obrigatório antes de programar

Antes de mexer nos userscripts ou no `dicionario_termos.json` deste repo,
leia primeiro:

1. **`.graphify/GRAPH_REPORT.md`** — resumo do grafo de código (funções mais
   conectadas, comunidades) gerado pelo graphify. Para detalhes de arestas
   específicas, consulte `.graphify/graph.json`.
2. O diagrama de arquitetura cruzando os dois repositórios (este +
   `consulta-precos-drogaraia`) vive em
   `../consulta-precos-drogaraia/docs/architecture.json` (repo privado,
   não duplicado aqui de propósito — este repo é público).

Este repositório é público só para os userscripts (Violentmonkey) poderem
buscar atualização direto do GitHub. Não colocar dados de preço, EAN ou
qualquer informação de negócio aqui.
